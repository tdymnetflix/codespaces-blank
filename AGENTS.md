# Hermes Agent Instructions

## Working agreement

- Inspect the repository and its existing conventions before changing files.
- Keep changes narrowly scoped to the Issue request.
- Run the smallest relevant test, lint, or build command after editing.
- Never print, commit, or expose credentials.
- Use Hermes memory for durable project facts and user preferences; it is stored under `.hermes/memories/`.
- Summarize changed files, checks run, and any remaining limitation in the final response.
